# Java-SuperMarket-Billing-System
Super Market Billing System is a Java console-based project developed using Object-Oriented Programming (OOP), File Handling, Classes & Objects, ArrayList, and Login Authentication System. This project simulates a real-life supermarket billing process where both Admin and User roles are available with different functionalities.

The system allows admins to add new products, update product stock, view available products, and manage sales records. Users can log in, view products, search products by name, add items to cart, and generate bills automatically. Product information, login data, and sales reports are stored using text files to provide permanent data storage.
